## 已核实的问题

首份候选只按实体键读取单个原始标志，未执行编码归一或业务放行判断。它是 source 事实查询，
不能输出完整的可释放报告清单。产品本就采用单事实 Agent 2 架构，因此不能把缺少整规则查询
本身判为实现违反当前契约；此前交付说明未充分说明其业务能力限制，应纠正。

固定资料对同一标志同时包含工作簿值域说明与参考视图比较条件，两者的编码不同。
候选原样读取该标志，未实现或证明转换关系。事实描述保留此差异，但静态通过不能消除它。
来源语义裁决完成前，不能把该查询称为与参考视图等价的放行事实或完整释放模板。

此外，候选 nullPolicy 保留 indeterminate，参考视图对该直接路径使用空值默认处理；
NULL 不命中该直接路径不等于整个规则最终不放行，因为还存在其他路径。
