### 2. `src/release_sql_bot/application/validate_handoff_closure_v3.py`（新增）

- `validate_handoff_closure_v3(closure: HandoffClosureV3) -> None`
- 六组有序 fail-fast 检查：
  1. `HANDOFF_STRUCTURE_INVALID` — 重验结构（防 model_copy 绕过）
  2. `HANDOFF_SCHEMA_SOURCE_INVALID` — Schema 加载器失败
  3. `HANDOFF_SCHEMA_REF_MISMATCH` — Schema 引用与常量不一致
  4. `HANDOFF_PAYLOAD_SCHEMA_INVALID` — payload 不符合冻结 JSON Schema
  5. `HANDOFF_IDENTITY_MISMATCH` — closure 与 payload 身份不一致
  6. `HANDOFF_PAYLOAD_HASH_MISMATCH` — payload 内容哈希不一致
- 复用 `application/handoff_intake_v3.py` 的加载器和常量
- 使用 `canonical_sha256` 重算 payload 哈希（与 V3 intake 一致）
- 纯计算：无仓储/provider/SQL/环境变量访问

### 3. `tests/unit/test_handoff_closure_validation_v3.py`（新增，36 项）
