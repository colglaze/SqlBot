## Phase 4 规划已完成

- 新增 REQ-20260827-01，冻结静态门禁的可信输入、范围、验收标准和 fail-closed 边界；
- 新增 DEV-20260827-01，选择 SQLGlot `30.17.x` 官方 `tsql` dialect，并通过 parser-neutral
  `SqlDialectInspector` 端口隔离具体 AST；
- 确定完整 parse 列表只能有一个非空 `SELECT`，拒绝 DML/DDL、`EXEC`、动态 SQL、集合运算、hint、
  `SELECT INTO`、外部源和未知安全结构；
- 固定唯一模板参数语法为 `:name`，要求 AST 实际参数与事实/候选参数精确一致，并限制在
  `WHERE`/`JOIN ... ON` 的值表达式；
- 确定用 scope-aware 数据源解析、完整离线元数据和 qualification 重新计算真实表/列引用，拒绝
  未限定/跨库对象、CTE 混淆、星号、未知/歧义/越权列；
- 确定同时从 AST 属性和对象形态拒绝 `#`/`##`、表变量、表值参数和 `SELECT INTO`；
- 确定 `usageCoverage` 只能由精确 `conditionId` 集合、事实引用和唯一 `fact_value` AST 投影重算，
  不冒充 RuleReader 的 operator、`NOT`、空值或时间边界语义证明；
- 静态报告始终固定 `executable=false`。本次仍未修改代码或依赖，未装配 SQL Server 驱动、连接或
  执行路径。
