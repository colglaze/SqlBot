## 阻塞/风险

- Phase 2E/3 没有遗留阻塞项；本地真实 MongoDB 验证依赖 Docker Desktop 和 `mongodb` 容器保持
  运行；
- 只接受已验证的 Schema `1.0.0`、`2.0.0`；RuleReader 新增版本时必须先扩展契约和夹具，否则
  明确返回 `RULE_DOCUMENT_INVALID`；
- “最新”只按版本生成时间选择，不隐式筛选生命周期状态。当前存量版本仍是不可执行草稿，API
  返回不代表批准或可用于生产查询；
- DeepSeek HTTP 协议已用固定响应验证，但本阶段未使用真实 API Key 做在线调用；模型可用性和输出
  质量不影响离线回归；
- SQL Server schema allowlist、完整字段、实体键和允许关系仍待真实元数据验证；Phase 3 的参数、
  对象声明和覆盖交叉检查不等于 SQL AST 安全证明；
- AST 安全校验、受限试跑、人工审核和发布仍未实现；因此所有候选始终 `executable=false`，当前
  没有 SQL 执行路径。
