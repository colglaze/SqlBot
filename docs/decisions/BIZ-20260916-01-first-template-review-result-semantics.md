## 模板交付与机器契约差异

现有单表 SELECT 没有 TOP/LIMIT、OFFSET、DISTINCT、聚合或分组，SQL 文本本身满足零行/全部匹配行
返回要求。保留原 SQL 字节与不可变候选，将审核意见单独记录为本地人工审核说明，关联精确哈希。

当前上游 queryRequirements.result、生成候选与生成响应契约仍限定 `cardinality=scalar`。
用户确认的多行返回不能被标记为已纳入这些机器契约；静态检查通过也不证明单行唯一性。
本轮完成 SQL 文本及人工审核资料交付，不扩展规则事实契约或实现查询执行 API。
以后将此模板接入多行取数时，须通过新版本上游交接及相应候选契约表达行集，禁止静默取第一条、
聚合、去重或修改已存候选来消除差异。
